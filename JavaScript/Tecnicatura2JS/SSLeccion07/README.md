🔹 Funciones que tienen que ver con la manipulación de datos

1. calculateTotalPrice()

🔸 Significado: Calcula el precio total de uno o varios productos.
🔸 Puntos importantes:

◼️ Realiza un cálculo basado en valores numéricos.
◼️ Indica que el resultado es un precio.
◼️ Muestra que combina o suma varios datos.

2. formatUserInput()

🔸 Significado: Da formato o limpia los datos que ingresa el usuario.
🔸 Puntos importantes:

◼️ Valida y estandariza la entrada del usuario.
◼️ La palabra format, indica que va a hacer una transformación.
◼️ Mejora la consistencia de los datos.
◼️ Hace que los datos sean utilizables por el programa.

3. validateEmailAddress()

🔸 Significado: Verifica si una cadena de texto tiene el formato correcto de una dirección de correo electrónico.
🔸 Puntos importantes:

◼️ Detecta errores comunes.
◼️ Indica que trabaja con correos electrónicos.
◼️ Evita errores en formularios o registros.
◼️ No garantiza que el email exista.
◼️ Permite entender que devuelve un valor booleano (true/false).

4. convertToCamelCase()

🔸 Significado: Convierte un texto a formato camelCase.
🔸 Puntos importantes:

◼️ Útil para nombrar variables en JavaScript de forma legible y estandarizada.
◼️ Indica transformación de texto.

5. filterActiveUsers()

🔸 Significado: Filtra solo los usuarios activos de una lista.
🔸 Puntos importantes:

◼️ Indica que trabaja con un conjunto de usuarios.
◼️ La condición suele basarse en una propiedad booleana.
◼️ No modifica el array original.
◼️ Puede combinarse con otras funciones



🔹 Eventos o Interacción
1. handleButtonClick()

🔸 Significado: Maneja lo que ocurre cuando se hace clic en un botón.
🔸 Puntos importantes:

◼️ Usa la palabra handle, típica para controladores de eventos.
◼️ Ideal para funciones en interfaces gráficas.
◼️ Es común en formularios, modales y componentes interactivos.

2. onFormSubmit()

🔸 Significado: Maneja el evento de envío de un formulario.
🔸 Puntos importantes:

◼️ "on" indica respuesta a un evento.
◼️ Accede a los valores del formulario.
◼️ Submit se asocia directamente con formularios.
◼️ Muy usado en validaciones antes de enviar datos.
◼️ Facilita la lectura del flujo de eventos.

3. toggleDarkMode()

🔸 Significado: Alterna entre modo claro y oscuro en la interfaz.
🔸 Puntos importantes:

◼️ Toggle indica cambio entre dos estados.
◼️ DarkMode define claramente la funcionalidad visual.
◼️ Muy común en configuraciones de usuario.
◼️ Refleja un efecto inmediato al usuario.

4. updateProgressBar()

🔸 Significado: Actualiza el estado de una barra de progreso.
🔸 Puntos importantes:

◼️ Usa update, que sugiere modificación de datos visuales.
◼️ Recibe un valor numérico como parámetro.
◼️ Se puede combinar con animaciones o texto.
◼️ Ideal para animaciones o tareas en curso.

5. initializeApp()

🔸 Significado: Inicia o prepara la aplicación para ejecutarse.
🔸 Puntos importantes:

◼️ Carga configuraciones iniciales.
◼️ Es el punto de partida del programa.
◼️ Suele llamarse una sola vez.
◼️ Muy común en estructuras de proyectos.



🔹 Operaciones CRUD
1. createNewUser()

🔸 Significado: Crea un nuevo usuario en el sistema.
🔸 Puntos importantes:

◼️ Create indica claramente que genera un nuevo registro.
◼️ El objeto User define el tipo de dato.
◼️ Sigue la convención CRUD.
◼️ Muy común en bases de datos.

2. fetchUserData()

🔸 Significado: Obtiene o trae los datos de un usuario.
🔸 Puntos importantes:

◼️ Recupera datos de usuario desde una fuente externa.
◼️ Precisa que trabaja con UserData.
◼️ Evita confusión con funciones de modificación.
◼️ Ideal para consultas a APIs o bases de datos.

3. updateUserProfile()

🔸 Significado: Actualiza la información del perfil de un usuario.
🔸 Puntos importantes:

◼️ Update representa modificación.
◼️ UserProfile delimita el tipo de información.
◼️ Muy usado en paneles o configuraciones de usuario.
◼️ Coherente con CRUD.

4. deleteUserAccount()

🔸 Significado: Elimina la cuenta de un usuario del sistema.
🔸 Puntos importantes:

◼️ Delete indica acción destructiva.
◼️ UserAccount especifica lo que se borra.
◼️ Es parte esencial de las operaciones CRUD.



🔹 Utilidades
1. generateRandomId()

🔸 Significado: Genera un identificador aleatorio.
🔸 Puntos importantes:

◼️ Generate indica creación de algo nuevo.
◼️ RandomId define el tipo de dato y su característica.
◼️ Muy útil en bases de datos o identificadores únicos.


2. formatCurrency()

🔸 Significado: Convierte un número en una cadena con formato monetario.
🔸 Puntos importantes:

◼️ Currency especifica el tipo de formato.
◼️ Ayuda a mostrar precios correctamente.
◼️ Mejora la legibilidad en interfaces financieras.

3. debounceSearch()

🔸 Significado: Retrasa la ejecución de una búsqueda hasta que el usuario deje de escribir.
🔸 Puntos importantes:

◼️ Evita ejecutar búsquedas excesivas.
◼️ Mejora el rendimiento de las búsquedas.
◼️ Evita llamadas innecesarias a funciones.
◼️ Muy útil en buscadores interactivos.

4. sanitizeInput()

🔸 Significado: Limpia los datos de entrada para evitar errores o ataques.
🔸 Puntos importantes:

◼️ Sanitize significa “desinfectar” o limpiar datos.
◼️ Protege contra código malicioso o contra ataques de tipo script.
◼️ Muy usado en seguridad web.
◼️ Se aplica antes de guardar o mostrar datos.

5. checkPermissions()

🔸 Significado: Verifica si un usuario tiene ciertos permisos.
🔸 Puntos importantes:

◼️ Check sugiere comprobación.
◼️ Permissions deja claro que es un control de acceso.
◼️ Común en sistemas con roles de usuario.
