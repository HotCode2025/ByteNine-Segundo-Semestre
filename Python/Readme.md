<summary><b>📜 GUIA ORGANIZACION BYTENINE</b>
</summary>
<br>

Para comenzar a trabajar y subir tnuestros cambios, seguimos estos pasos y comandos:
<details>
<summary><b> Pasos y Comandos  </b>
</summary>
<br>
 

1.  **Clonar el repositorio:**
 En nuestro escritorio, creamos una carpeta con el nombre `Segundosemestre-ByteNine`. Luego, abrimos la terminal de Git Bash dentro de esa carpeta y clonamos el proyecto usando la dirección SSH.

    ```sh
    git clone git@github.com:HotCode2025/ByteNine-Segundo-Semestre.git # Clonamos el repositorio en nuestra máquina local
    ```

2. **Sincronizar y entrar a nuestra rama de trabajo:** 
La rama principal (`main`) solo será actualizada por nuestro owner. **Siempre** debemos sincronizar los archivos y trabajar en la rama secundaria.

    ```sh
    git checkout main # Nos aseguramos de estar en la rama principal para traer los últimos cambios
    git pull origin main #Traemos las actualizaciones.
    git checkout Bytenine---Seguridad #Entramos a nuestra rama de trabajo "Bytenine---Seguridad"
    ```

3.  **Realizar y agregar tus cambios:**
 Ahora abrimos la carpeta en Visual Studio Code. Trabajamos en los  archivos designados y, cuando terminemos, agregamos los cambios al área de preparación.

    ```sh
    code . # Abrimos el proyecto en VS Code y empiezamos a trabajar
    git status # Revisamos los archivos modificados
    git add .  # Agregamos todos los archivos nuevos o modificados
    ```

4.  **Confirmar y subir subir nuestra contribución:** 
Confirmamos nuestros cambios y subimos  a la  rama secundaria.

    ```sh
    git commit -m "Se agregan ejercicios de la Clase 1: Ciclos y condicionales" # Confirmamos los cambios con un mensaje claro
    git push origin Bytenine---Seguridad # Subimos los cambios a nuestra rama de trabajo secundaria
    ```

    _**Nota Importante:** Una vez que subimos nuestros cambios, nuestro owner revisara el trabajo y decidira  fusionarlo con la rama principal._

### Como hicimos nuestras lecciones

1. **Creamos un Proyecto:** 
* La escritura a utilizar sera CamelCase .
 * Utilizaremos los Nombres que estan en los videos para darle nombre a nuestras clases.

 * Dentro de la carpeta del lenguaje creamos una nueva carpeta, la cual sera nuestro **PackageProyecto**(ej. `Clase1`)Luego creamos nuestro **Archivo**(por ejemplo`Listas1.py` ).


2. **Ejecutamos el código:**
* **Desde la terminal:** 
Navegamos hasta la carpeta del archivo.

 ```sh
 cd Python/Clase1
 ```
* **Compilacion:**
```sh
 javac NombreDeLaClase.py
 ```
* **Ejecucion:**
```sh
 python NombreDeTuClase
```
* Una vez que estemos seguros de su correcta ejecucion seguimos los pasos de la guia de inicio(punto3)
